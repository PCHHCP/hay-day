# HayDay 抢购自动化脚本

## 目标 (Goal)

在 macOS + BlueStacks 环境下，实现 HayDay 游戏报纸抢购 6 种扩建工具（Bolt / Nail / Panel / Tape / Plank / Screw）的半自动化脚本，毫秒级响应，与真人玩家拼手速。

## 运行环境

- **宿主**: macOS 26，BlueStacks Air（Apple Silicon 原生）
- **BlueStacks 设置**: 分辨率 `1080×1920 @ 320dpi`（纵向手机模式），窗口大小锁定，关闭 FXAA/抗锯齿
- **开发语言**: Python 3.11+
- **核心依赖**:
  - `mss` — 屏幕截图（初期简单可用）
  - `opencv-python` — 图像匹配（模板匹配 + ORB 特征点）
  - `numpy` — 数值支持
  - `pyobjc-framework-Quartz` — 定位 BlueStacks 窗口
  - `pyobjc-framework-ScreenCaptureKit`（后期）— 性能关键路径替换 mss

## 核心架构决策

| 决策点 | 选择 | 原因 |
|---|---|---|
| 截图 | 初期 mss，后期 ScreenCaptureKit | 先验证流程，性能后调优 |
| 点击 | 主：`CGEventPostToPid` 定向 BlueStacks，降级：ADB (BlueStacks 5555 端口) | 不影响用户 mac 其他操作；ADB 作为兜底 |
| 触发方式 | 半自动（快捷键触发一次完整流程） | 避免长时间挂机被检测 |
| 邮箱识别 | ORB 特征点匹配（因为是 3D 世界物体，会随视角缩放平移） | 抗缩放/平移/轻度旋转 |
| UI 元素识别 | 普通模板匹配（报纸、货架、工具、购买、关闭按钮） | UI 是固定 overlay，屏幕坐标稳定 |
| 失败处理 | 看到就点、点不上跳过、绝不重试 | 节省时间抢下一个广告 |

## 流程规格

```
1. 主界面 → 识别邮箱（ORB） → 点击
2. 报纸打开 → 扫描第一页的所有广告卡片
3. 对每个广告 → 依次匹配 6 种工具模板
4. 命中工具广告 → 点击广告
5. 进入玩家货架 → 再次识别目标工具（位置不固定）→ 点击购买
6. 点击关闭 → 回到报纸 → 尝试下一个广告
7. 第一页扫完 → 脚本结束（不翻页）
```

## 目标 6 种工具

建仓/筒仓扩建材料，均为硬件类小物件：

| 英文 | 中文 | 视觉特征 |
|---|---|---|
| Bolt | 螺栓 | 六角头 + 螺纹 |
| Nail | 钉子 | 尖头，一个圆头 |
| Screw | 螺丝钉 | 螺纹 + 十字头 |
| Panel | 木板（宽） | 宽矩形木片 |
| Plank | 木板（长条） | 长条形木片 |
| Tape | 胶带 | 圆盘/卷轴 |

⚠️ Bolt / Screw 视觉相似；Panel / Plank 视觉相似——模板要抠得精细。

## 验收标准 (Acceptance Criteria)

### Phase 1：模板捕获工具 + 可行性验证 [当前]
- [ ] `capture_template.py` 能识别 BlueStacks 窗口并截图
- [ ] 支持交互式裁剪，输出命名的模板 PNG
- [ ] 支持对指定模板+快照做模板匹配测试，输出置信度+可视化
- [ ] 用户能用此工具抓出 6 种工具的初版模板
- [ ] 6 种工具在报纸全景图上的模板匹配置信度 ≥ 0.8（验证可行性）

### Phase 2：邮箱识别（ORB）
- [ ] 基于 ORB 的邮箱识别 ≥ 95% 成功率（不同视角/缩放下 10 次测试 ≥ 9 次命中）
- [ ] 识别失败时自动降级到多尺度模板匹配
- [ ] 最终失败时暂停脚本并提示手动点击

### Phase 3：点击注入
- [ ] `CGEventPostToPid` 定向点击 BlueStacks 生效（不影响用户鼠标）
- [ ] 失败时自动降级到 ADB（BlueStacks 5555 端口）
- [ ] 单次点击延迟 < 20ms（原生）或 < 200ms（ADB）

### Phase 4：主循环整合
- [ ] 快捷键触发完整流程
- [ ] 第一页抢购一轮 < 3 秒
- [ ] 完整抢购流程在标准场景下命中率 ≥ 80%

## 技术备注

- **窗口位置**：脚本每轮动态查询 BlueStacks 窗口坐标，支持用户任意拖动
- **Retina 显示**：注意捕获像素可能是窗口点尺寸的 2×
- **坐标系**：模板匹配在"像素空间"，点击在"点空间"，需做坐标转换
- **不翻页**：HayDay 报纸多页，但后续页基本抢不到，仅扫第一页
